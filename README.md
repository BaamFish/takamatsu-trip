# 高松旅記｜瀨戶內家庭旅行部落格

公開網站：https://baamfish.github.io/takamatsu-trip/

2026/11/02–11/06，三位成人、五天四夜。網站以公開閱讀與分享為主，提供旅行故事、每日路線、交通住宿、實際花費與景點資訊。行前待辦、日文練習及私人訂單輸入介面不再出現在網站。

## 頁面與資料

- `src/App.jsx`：導覽、分享、舊書籤對應與交通住宿頁。
- `src/JournalPages.jsx`：首頁、行程文章、旅費與景點頁。
- `src/journal.js`：五天文章、景點資訊、去識別化的訂單核對摘要。
- `src/budget.js`：現金概算、已配對刷卡通知、Suica 扣款與儲值分類。
- `src/photoCredits.json`：每張照片的作者、原始檔頁與授權網址。
- `public/photos/`：下載並縮圖壓縮的開放授權景點照片。
- `src/journal.css`：桌面雜誌版面與手機導覽。

文章可直接分享 `#day-1` 至 `#day-5`；其餘頁面為 `#home`、`#daily`、`#travel`、`#expenses`、`#places`。舊的 `#prepare` 對應旅費，`#transport`／`#reservations` 對應交通住宿，`#japanese` 回到首頁。舊版工具的原始元件仍保留在 Git 歷史與工作檔，未被目前入口引用，不參與公開介面。

## 部署與修改

GitHub Pages 的 Source 使用 GitHub Actions。修改後執行測試與正式編譯，推送 `main`；`.github/workflows/deploy.yml` 會自動建置並部署。無需把 `dist` 直接提交到主分支。若已安裝的 PWA 暫時仍顯示舊內容，可重新開啟或按更新提示。

新增正式帳單時，先確認退款、金額幣別及儲值移轉，排除與現金彙總、票券訂單和刷卡通知重複的項目，再更新旅行總額。請勿將原始金融文件放進公開資料夾或 Git。
